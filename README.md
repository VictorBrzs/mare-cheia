# Maré Cheia 🌊

Site institucional criado para divulgação de cardápios virtuais, ideal para apresentar soluções digitais para restaurantes, lanchonetes e negócios do setor alimentício.

## 📋 Sobre o Projeto

O **Maré Cheia** é uma landing page moderna e estratégica, desenvolvida para demonstrar como um cardápio virtual pode ajudar estabelecimentos a aumentar vendas, melhorar a experiência do cliente e modernizar o atendimento.

O projeto utiliza informações fictícias para fins de apresentação e portfólio.

## ✨ Objetivo

Apresentar, de forma visual e persuasiva, os benefícios de um cardápio digital, como:

- Maior praticidade no atendimento
- Aumento nas vendas
- Integração com canais digitais
- Melhor experiência para o cliente
- Presença online profissional

## 🎨 Design

O design foi desenvolvido pela ARENA.IA, com foco em:

- Interface moderna e atrativa
- Navegação intuitiva
- Layout responsivo
- Alta conversão

## 🛠️ Tecnologias Utilizadas

- React
- TypeScript
- Vite
- Tailwind CSS

## 📱 Responsividade

O site foi projetado para oferecer uma experiência consistente em:

- Desktop
- Tablet
- Smartphones

## 🚀 Funcionalidades

- Apresentação dos benefícios do cardápio virtual
- Seção de recursos e diferenciais
- Planos e ofertas
- Depoimentos de clientes
- Formulário de contato
- Integração com WhatsApp

## 📌 Observações

Este projeto foi desenvolvido com conteúdo fictício, servindo como modelo demonstrativo para apresentação comercial e portfólio.
